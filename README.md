## نشر مجاني مقترح
يمكن نشر هذه الملفات على GitHub Pages أو خدمة استضافة صفحات ثابتة مجانية.
بعد النشر، استخدم:
- الصفحة الرئيسية: رابط index.html
- سياسة الخصوصية: رابط privacy.html
- شروط الاستخدام: رابط terms.html

مهم: لا تضع روابط localhost أو روابط غير عامة في Google Auth Platform.
